# Frontend Design Skill Guide

> Source: [anthropics/skills - frontend-design](https://github.com/anthropics/skills/tree/main/skills/frontend-design)

## Overview
Guidance for distinctive, intentional visual design when building new UI or reshaping an existing one. Helps with aesthetic direction, typography, and making choices that don't read as templated defaults.

## Design Philosophy & Principles

### 1. Ground it in the subject
- Pin down the concrete subject, audience, and the page's single job before designing.
- Draw inspiration from the subject's own world: its materials, instruments, artifacts, and vernacular.
- Build with the brief's real content and subject matter throughout.

### 2. The hero is a thesis
- Open with the most characteristic thing in the subject's world (live demo, interactive gauge, clear headline statement).
- Avoid template answers like a plain big number with a small label unless it is truly the best option.

### 3. Typography carries personality
- Pair display and body faces deliberately.
- Set a clear type scale with intentional weights, widths, and line height.
- Make typography a memorable part of the design, not just a neutral text delivery tool.

### 4. Structure is information
- Structural devices (dividers, labels, eyebrows, numbering) should encode true content structure, not decorate.
- Only use numbered markers (01, 02, 03) if the content is an actual sequence or typed timeline.

### 5. Leverage motion deliberately
- Use ambient atmosphere, scroll reveals, and micro-interactions where they serve the subject.
- Orchestrate motion moments; avoid scattered or noisy animations that look like generic templates.

### 6. Avoid AI-generated clichés
- AI designs often cluster around:
  1. Warm cream background (#F4F1EA) + high-contrast serif + terracotta accent
  2. Near-black background + single bright acid-green / vermilion accent
  3. Broadsheet newspaper layout + zero border-radius
- Choose a distinctive, custom palette tailored to the domain (e.g., damda: HSL mint/emerald, glassmorphism, clean dark/light mode for skin health).
